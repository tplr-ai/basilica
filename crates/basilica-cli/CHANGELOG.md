## [0.10.0] - 2025-01-01

### Added
- Unified CLI for Basilica network management
- `login` - OAuth2 authentication
- `deploy` - Deploy workloads to GPU nodes
- `rentals` - Manage active rentals
- `gpus` - List and filter available GPUs
- `logs` - Stream workload logs
- `exec` - Execute commands in rentals
- `ssh` - SSH into rentals
- `billing` - View usage and billing
- `config` - Manage CLI configuration
- `completions` - Shell completion generation
- `update` - Self-update functionality
- Progress indicators and colored output
- Configuration file support
- Environment variable overrides
