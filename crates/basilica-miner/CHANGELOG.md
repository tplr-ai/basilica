## [0.1.0] - 2025-01-01

### Added
- Bittensor subnet miner implementation
- GPU node fleet management
- Axon server for Bittensor discovery
- gRPC server for validator authentication
- SSH key deployment to managed nodes
- Validator assignment and routing
- SQLite storage backend
- Node health monitoring
- Collateral contract integration
- Prometheus metrics export
