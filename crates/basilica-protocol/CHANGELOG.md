## [0.1.0] - 2025-01-01

### Added
- gRPC protocol definitions for Basilica network communication
- MinerDiscovery service: validator authentication and node discovery
- Billing service message types
- Common message types shared across services
- Tonic-based gRPC code generation

### Features
- `client` - Enable client-side gRPC stubs
- `server` - Enable server-side gRPC stubs
