## [0.1.0] - 2025-01-01

### Added
- Payment processing for Basilica network
- TAO cryptocurrency integration
- User wallet generation and management
- Deposit monitoring from Bittensor blockchain
- Balance tracking and updates
- gRPC API for service integration
- REST API for external access
- PostgreSQL storage with migrations
- `paymentsctl` CLI tool
- Prometheus metrics export
- Health check endpoints
