## [0.10.0] - 2025-01-01

### Added
- `BasilicaClient` for API interactions
- `ClientBuilder` for fluent client configuration
- GPU listing and filtering operations
- Rental creation, management, and lifecycle
- Log streaming support
- Billing and usage queries
- OAuth2 authentication support
- API key authentication
- Comprehensive error types with retry hints

### Changed
- Extracted from `basilica-api` for better code reuse

### Features
- `client` - Enable full client functionality (default)
