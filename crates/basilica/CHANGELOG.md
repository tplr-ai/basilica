## [0.1.0] - 2024-12-27

### Added

- Initial release of unified `basilica` crate
- Re-exports all component crates with feature flags
- `sdk` feature (default) - High-level client SDK
- `cli` feature - Command-line interface
- `validator` feature - Validator node implementation
- `miner` feature - Miner node implementation
- `api` feature - REST API server
- `full` feature - Enable everything
- Unified documentation with cross-linking
- Prelude module for convenient imports
